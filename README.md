# ACR-MCR Dynamic IoT WSN — Supporting Data

This public repository contains the supporting research data, statistical-analysis materials, packet-level validation outputs, and reproducibility code for the manuscript:

**Adaptive Conformal Clustering and Routing in Dynamic IoT Sensor Networks Under Explicit Telemetry Costs**

submitted to **Discover Networks**.

## Repository contents

### `reproducibility/`
Contains the simulation implementation and scripts used to generate and analyse the reported results.

### `statistical_analysis/`
Contains the statistical-analysis description and audited statistical output.

### `ns3_validation/`
Contains the ns-3 IEEE 802.15.4 mechanism-validation source, documentation, and summary data.

## Primary simulation data

The frozen primary 20-seed simulation results and paired statistical results supporting the manuscript are provided in this repository as:

- `raw_results/raw_20seed.csv`
- `statistical_analysis/paired_stats_20seed.csv`
- `raw_results/sensitivity_S5.csv`

These files correspond to the manuscript's reported simulation and sensitivity analyses.

## Data provenance

The study is simulation-based. No external human-subject, clinical, or proprietary dataset was used. The research data were generated by the simulation and validation procedures included in this repository.

## Reproducibility

Install the Python dependencies with:

```bash
pip install -r reproducibility/requirements.txt
```

The principal simulation and analysis scripts are available under `reproducibility/`.
